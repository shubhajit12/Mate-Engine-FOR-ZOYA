# Zoya Mate Engine

A lightweight desktop companion runtime for the **ZOYA** project.

## Purpose

Zoya Mate Engine provides the desktop companion layer used by **ZOYA**, including:

- Desktop avatar presence
- Window and taskbar interactions
- Dragging and idle behavior
- VRM avatar support
- Animation and expression systems
- Customizable desktop UI
- Performance controls
- Companion features used by ZOYA

The runtime is customized specifically for ZOYA and is intended to be launched as the companion engine.

## Development

This is a Unity project.

1. Open the project with the Unity version specified in ProjectSettings/ProjectVersion.txt.
2. Open the ZOYA companion scene.
3. Build the Windows player when testing a standalone companion runtime.

The generated Windows runtime must contain the executable together with its complete Unity data directory and required runtime files.

## ZOYA branding

The visible product identity is **Zoya Mate Engine**.

The companion UI uses the ZOYA dark/amber visual theme and the English-only interface configured for the project.
